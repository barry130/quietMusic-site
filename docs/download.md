## 选择你的平台

| | Android | Windows |
|---|---|---|
| 包名 / 应用 ID | `com.qt.app` | `com.qt.quietmusic` |
| 产品名 | 轻听 | QuietMusic（显示名「轻听」） |
| 安装形态 | APK | NSIS 安装包 `.exe` |
| 系统要求 | Android（建议 8.0 及以上） | Windows 10 / 11（需 WebView2） |
| 获取方式 | 见下方 Android 段 | 见 [GitHub Release](https://github.com/barry130/qt-pc/releases) |

两个客户端共用同一份音源包产物——**一份实现两端生效**。

## Android

**推荐做法**：打开已安装的轻听 → 「我的」→「检查更新」。
客户端会向后端查询当前正式版 / 测试版，弹窗后直链下载并自动安装。

首次安装（还没装过任何版本）才需要走本页的直链。

### 安装步骤

1. 下载 APK 到手机
2. 点击安装，系统会提示「允许安装未知应用」——按引导授权
3. 安装完成首次启动，按引导授予**存储**与**通知**权限
4. 进入「设置 → 音源包管理」安装音源包（**在线功能的关键一步**，见下方
   [安装音源包](#安装音源包)与[如何设置音源](/source-setup)）

### 权限说明

| 权限 | 用途 | 不授权会怎样 |
|---|---|---|
| `INTERNET` | 在线搜索、播放、歌词、封面、收藏同步 | 在线功能全不可用 |
| `POST_NOTIFICATIONS` | 播放通知栏控件 | 后台播放没有通知栏控件 |
| `READ_MEDIA_AUDIO` | 扫描本地音乐 | 扫不到本地曲库 |
| `MANAGE_EXTERNAL_STORAGE` | 删除第三方公共媒体文件 | **不开启也能正常用**，只是删不掉公共目录的文件 |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK` / `WAKE_LOCK` | 后台播放不中断 | 切后台可能被系统回收 |
| `SYSTEM_ALERT_WINDOW` | 桌面歌词悬浮窗 | 桌面歌词打不开 |
| `REQUEST_INSTALL_PACKAGES` | 应用内下载后直接安装更新 | 更新要手动装 |

::: details 为什么要声明明文流量（`usesCleartextTraffic`）？
酷我 / 酷狗 / QQ / 网易云等第三方接口与封面大量使用 `http://`。
Android 9+ 默认禁止明文流量，不放行就会直接报 `CLEARTEXT not permitted`。
这是为了兼容第三方接口的现实，**不影响应用自身与后端的通信**（走 https）。
:::

## Windows

从 [qt-pc 的 GitHub Release](https://github.com/barry130/qt-pc/releases) 下载
`QuietMusic_<版本>_x64-setup.exe`；也可以在
[CNB 镜像仓库](https://cnb.cool/canace/qt-pc)查看代码与构建记录。

### 安装步骤

1. 下载 `.exe` 安装包（NSIS）
2. 双击安装；如果系统缺少 WebView2，安装器会**自动下载引导安装**
3. 首次启动后进入「设置 → 音源包」安装音源包

::: warning 安装包必须带签名
应用内更新在安装前会**强制验签**：没有同名 `.sig` 或验签失败的包**一律拒绝安装**。
从 Release 下载时请把 `.exe` 与 `.exe.sig` 放在同一目录。

校验命令（仓库内脚本）：

```bash
node scripts/update-sign.mjs sign "src-tauri\target\release\bundle\nsis\QuietMusic_<版本>_x64-setup.exe"
node scripts/update-sign.mjs verify "src-tauri\target\release\bundle\nsis\QuietMusic_<版本>_x64-setup.exe"
```
:::

::: tip 应用内更新怎么工作
更新走的是**后端更新记录**，所以：

- Release 页只负责**托管安装包**；
- 更新提示、下载地址与完整性校验信息由后端下发；
- 下载完成后校验完整性，验签通过才启动安装器。

这样更新链路可控，也能在发现问题的第一时间调整下发内容。
:::

## 安装音源包

这是**让在线功能生效**的关键一步。没装的话本地播放照常，但在线搜索与播放不出现。

三种安装方式：**检查更新（官方包，推荐）**、**粘贴 https 直链**、**选择本地文件**。
完整说明、兼容 LX 音源脚本的细节、多包切换与默认音源设置，都在
[**如何设置音源**](/source-setup) 这一页。

### 包名说明

| 包 | id | 作用 | 版本号规则 |
|---|---|---|---|
| 官方数据包 | `meta-official` | 搜索 / 歌单 / 歌词 / 封面等**元数据**入口 | `YYYYMMDD` + 2 位序号 |
| 官方播放包 | `play-official` | 在线**取链**（播放地址解析），风险较高 | 同上，且不得低于后端已发布的最大值 |

`play-official` 与 `meta-official` 是官方保留 id，**只有带官方 ed25519 签名的包
才能用这两个 id 安装**。第三方包请用自己的 id（`^[a-z0-9-]{2,32}$`）。

::: details 签名是怎么做的
构建期对「含身份头的全文」做 ed25519 签名，产物尾部追加签名块；
两端宿主内置公钥、对官方 id **硬校验**——改一个字节就装不上。

公钥是公开信息（随宿主源码分发）：

```
mOti+JoaX2Tn6VaP91E+TaYrth4oGaUqASv9Ot4NDcE=
```

私钥只在发布机上、绝不入仓库。他人 clone 后自行构建若没有私钥，
产物的官方 id 会被宿主拒绝安装——这是预期行为。
:::

## 卸载音源包

在音源包管理页删除即可。

**卸载后在线能力消失，其余一切照常**——播放、歌词、下载、收藏全部继续工作。

---

## 验证安装是否成功

装完播放包后客户端会做一次**冒烟自检**：拿几首真实歌曲调用取链 + Range 预检。

- 通过 → 立即生效
- 不通过 → **回滚**（更新场景回滚旧版；首次安装保留文件并标注「上次失败」）

**手动验证**：随便搜一首歌 → 播放 → 能出声就说明整条链路通了。

## 遇到问题

先看 [问题答疑](/faq)。常见的三类：

| 现象 | 先试什么 |
|---|---|
| 首页提示「未安装播放音源包」 | 音源包管理页 → 检查更新 |
| 搜索能用但播放失败 | 检查播放包是否为最新版；换一首 / 换音源 |
| 安装包被拒绝 | 官方 id 需要官方签名；第三方包请用自己的 id |

若仍无法解决，请通过应用内「意见反馈」或[反馈与贡献](/feedback)里的渠道提交——
提交时**设备型号、系统版本与应用版本号**会一并上传，便于定位
（详见[隐私政策](/privacy)）。
