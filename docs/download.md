::: warning 安装包必须带签名
应用内更新在安装前会强制验签：没有同名 `.sig` 或验签失败的包**一律拒绝安装**。
从 Release 下载时请把 `.exe` 与 `.exe.sig` 放在同一目录。
:::

## 安装音源包

这是**让在线功能生效**的关键一步。没装的话，本地播放照常，但在线搜索与播放不可用。

### 方式一：官方包（推荐）

1. 打开「设置 → 音源包管理」
2. 点「检查更新」，客户端从官方清单拉取直链并下载
3. 安装前会展示包的身份（类型 / 名称 / 版本 / id / 来源），官方包会显示「已验签」
4. 确认后自动落盘 + 冒烟自检，通过即生效

官方包支持自动更新：启动预热 + 4 小时节流的静默检查，发现新版本提示你。

### 方式二：自定义直链

在设置页粘贴一个 **https 直链**（http 会被拒绝），客户端下载并走同样的安装流程。
自定义包**不参与自动更新**，升级需重新粘贴链接。

::: tip 多包并存
可以同时装多份播放包，同一时刻只有一个生效。列表每行会显示来源（链接 / 本地 /
官方）与最近失败原因，切换即时热装载并做取链冒烟自检——试错成本很低。
:::

### 包名说明

| 包 | id | 作用 |
|---|---|---|
| 官方数据包 | `meta-official` | 搜索 / 歌单 / 歌词 / 封面等**元数据**入口，官方单版本 |
| 官方播放包 | `play-official` | 在线**取链**（播放地址解析），风险较高，由用户自行安装 |

`play-official` 与 `meta-official` 是官方保留 id，**只有带官方 ed25519 签名的包
才能用这两个 id 安装**。第三方包请用自己的 id（`^[a-z0-9-]{2,32}$`）。

## 卸载音源包

设置页删除即可。**卸载后应用仍是完整的本地音乐播放器**——本地音乐、播放、歌词、
下载、收藏全部照常工作，只有在线能力消失。

---

## 验证安装是否成功

装完播放包后客户端会做一次**冒烟自检**：拿几首真实歌曲调用取链 + Range 预检。
通过才生效，不通过会回滚（更新场景回滚旧版，首次安装保留文件并标注「上次失败」）。

手动验证：随便搜一首歌 → 播放 → 能出声就说明整条链路通了。
