# 功能介绍

轻听的**核心是本地音乐播放器**。下面按「本地」「在线」「两端差异」三块说明。

---

## 本地音乐（开箱即用，无需音源包）

| 能力 | Android | Windows |
|---|---|---|
| 扫描本地目录建库 | ✅ 全盘 / 指定文件夹，可设最小文件大小过滤 | ✅ 目录级管理 |
| 支持格式 | MP3 / FLAC / WAV / OGG / AAC / M4A | MP3 / FLAC / WAV / OGG / AAC / M4A |
| 播放与队列 | ✅ 顺序 / 列表循环 / 单曲循环 / 随机 | ✅ 同 |
| 歌词 | ✅ 滚动歌词、歌词翻译、字号调节、全屏歌词 | ✅ 桌面歌词窗口 |
| 下载管理 | ✅ 后台持续下载、进度实时、音质可选 | ✅ 进度写库、任务列表 |
| 听歌统计 | ✅ 累计播放 / 收藏 / 活跃天数 / 最常播放 | ✅ 播放次数、时长、热门曲目与歌手排行 |
| 收藏与歌单 | ✅ 自建歌单，登录后可云同步 | ✅ 自建歌单，与后端账号云同步 |

::: tip Windows 端不支持的格式
APE / WMA / DSD 暂不支持（解码依赖 symphonia）。
:::

## 在线聚合（需安装音源包）

在线能力全部由**音源包**提供，仓库本身不包含任何第三方取链实现。
数据面（搜索 / 歌单 / 歌词 / 封面）随**官方数据包**下发，取链面由**播放包**承担。

### 支持的音源

音源清单由音源包自己声明并下发，客户端不内置任何白名单——包里加一行，
该源立刻在两端可选、可搜、可播放。

| 音源 | id | 短名 |
|---|---|---|
| 网易云音乐 | `wyy` | 网易 |
| QQ 音乐 | `qq` | QQ |
| 酷我音乐 | `kw` | 酷我 |
| 酷狗音乐 | `kg` | 酷狗 |
| 哔哩哔哩 | `bili` | B 站 |
| 咪咕音乐 | `migu` | 咪咕 |

::: warning 功能面因源而异
不是每个源都有全部入口。比如 B 站没有歌单载体，「歌单广场」对它永远是空的——
客户端会按音源包声明的功能面**自动隐藏**这些入口，而不是给你一个空列表。
:::

### 在线能力清单

- **搜索**：跨源聚合，按音源包声明的每页上限分页
- **歌单广场 / 热门歌单 / 每日推荐**：排序选项也由包声明（如酷狗的「最热 / 最新 / 推荐」）
- **排行榜 / 新歌速递 / 热门搜索词**
- **歌手页 / 专辑页**：各平台能力不齐，缺的字段留空而非编造
- **歌词**：普通 LRC + 翻译；音源包支持时另有**逐字歌词**与**罗马音**两种可选面
- **同歌多源**：播放时可切换音源，优先选可用的高音质来源
- **在线播放缓存**：Android 端边播边缓存到本地（LRU 上限可调），重复播放不走网络
- **音质**：标准 128k / 高品 320k / 无损 FLAC，播放与下载音质相互独立

## 两端各自的特色

### Android（qt-uniappx）

- **原生后台播放**：BackgroundAudioManager，锁屏 / 后台持续播放，通知栏控件齐全
- **桌面歌词**：系统悬浮窗，逐行跟随、可拖动、可锁定（锁定后点击穿透不影响操作）；
  字号 / 颜色 / 字体可调并即时生效。开关是运行期状态，**每次启动默认关闭**
- **播放失败自动切歌**：播放失败跳下一首，连续多次失败自动停下并提示
- **播放倍速**、播放队列、下一首播放
- **账号体系**：邮箱 / 用户名登录、邮箱验证码找回密码、签到积分、编辑资料
- **收藏同步**：登录后自动同步，断网暂存、联网补推；每次启动做存在性对账
- **公告与消息中心**：开屏弹窗、首页跑马灯、消息中心未读红点
- **外观与皮肤**：明暗模式、Linen / Graphite / Aurora 预置皮肤、自定义背景与配色，
  宽屏设备（≥720px）自动切宽屏布局
- **启动校验官方版本**：非官方版本提示后 3 秒自动退出

### Windows（qt-pc）

- **HTTP Range 流式播放**：边下边播，拖动进度条即时定位
- **独立桌面歌词窗口**：置顶、锁定 / 穿透、自定义样式
- **自动更新**：官方版本校验 + 加速节点下载 + MD5 校验
- **外观与快捷键**：浅色 / 深色 / 跟随系统、封面色取色主题、全局快捷键
- **音源包机制**：从链接安装，官方包支持自动更新，也可粘贴自定义直链

## 音源包机制（为什么这么设计）

传统的做法是客户端内置各家接口，接口一变就只能发新版 App。轻听把这部分拆出去：

```
┌─────────────┐     安装/更新      ┌──────────────────┐
│  客户端      │  ←──────────────  │  音源包（.js）     │
│ （不含取链） │                    │  取链 + 数据面     │
└─────────────┘                    └──────────────────┘
       ▲                                    ▲
       │ 执行于本地引擎                       │ 官方 ed25519 签名
       │（Android: WebView V8）              │  + 内容安全扫描
       │（Windows: 引擎页）                   │
```

- **多包并存**：可同时装多份播放包，设置页选一份启用，切换即时热装载并做取链冒烟自检
- **冒烟自检**：装完先拿真实歌曲取链 + Range 预检，不过就回滚，不会把你卡在坏包上
- **官方签名**：官方包带 ed25519 签名，客户端内置公钥硬校验，改一个字节就装不上
- **内容安全扫描**：安装时扫包文本，命中宿主桥 / 自由外联 / 后台执行体等红线直接拒绝
- **运行时能力收缴**：包里能用的只有 `host.request` 一个网络出口，
  `fetch` / `XMLHttpRequest` / `WebSocket` / `Worker` / 文件系统全是 `undefined`

> 未安装播放包时，在线播放不可用，但**本地音乐与在线搜索不受影响**。

## 已知限制

- 不支持 APE / WMA / DSD（解码依赖 symphonia）
- 未安装音源包时搜索 / 榜单 / 在线歌单不可用（本地音乐不受影响）
- 部分音源的无损取址在无无损源时会回退到有损，下载扩展名按实际返回的 URL 决定
- 逐字歌词、罗马音仅在音源包支持时可用
- 桌面歌词、本地文件删除依赖系统权限，不同厂商机型入口位置有差异
- 鸿蒙系统暂未单独适配
