> **最后更新**：2026-10-07 · 适用于轻听 Android 端与 Windows 桌面端

## 1. 项目定位

轻听的**本地音乐能力开箱即用**：曲库扫描、播放、歌词、下载管理等核心功能
**不依赖任何在线音源**。

在线试听、搜索、歌单等能力是**可选增强**，依赖运行时安装的「音源包」提供，
默认不包含、也不强制使用。

::: tip 一句话概括
把本地音乐播好是本分；在线能力是附赠的、随时可能失效的额外功能。
:::

具体地，不需要任何音源包就能用的功能包括：扫描并播放本地音乐（mp3 / flac / wav /
ogg / m4a / aac）、歌词（内嵌与同名 `.lrc`）、播放队列与播放模式、听歌统计、
歌单管理、下载管理、均衡器、定时关闭、桌面歌词（Android）、外观与皮肤。

需要音源包的功能包括：在线搜索、在线歌单、排行榜、每日推荐、在线歌词与封面、
在线试听与下载。

## 3. 仓库不含音源实现

出于版权合规考虑，本项目**不内置、不携带、不分发任何第三方音源实现**。
音源包不属于本项目的一部分，其**内容、来源与合法性由提供方与使用者自行负责**。

- **官方包**：由独立渠道下发直链，客户端下载安装并自动更新，带 ed25519 签名
- **自定义包**：使用者自行粘贴直链或从本地文件安装，不参与自动更新，
  升级需重新粘贴链接

客户端仓库里确实**不包含** `source-bundle.js` / `chain.json` 及其任何构建产物，
也**不包含任何音源接口实现**。仓库里只有：播放器与界面、原生插件（音频内核 /
音源包执行引擎 / 悬浮窗歌词等），以及执行「使用者提供的脚本」所需的通用能力。

取链实现不在任何带开源许可证的仓库中，也**不授予任何授权**。

## 4. 音源包与第三方内容

你通过音源包访问的任何第三方接口与内容，其**合法性、版权与风险由你自行承担**。
本项目：

- 不存储、不缓存、不转发任何受版权保护的音乐内容
- 不对音源包的可用性、音质、稳定性作任何担保
- 无法保证播放结果与你所期望的曲目一致（换源机制天然存在翻唱、Live、串曲的可能）
- 不参与、不记录、不代理音源包发出的请求；请求目标地址由音源包决定

第三方音源包在安装时会被扫描，命中[内容安全红线](/dev/source-pack#内容安全红线)
的包会被直接拒绝安装；运行时 `fetch` / `WebSocket` / `Worker` / 宿主原生桥等能力
已被收缴，包只能使用宿主注入的 `request` 通道。

::: warning 但这不等于「官方背书」
打包扫描只能证明**包做不了取链以外的事**，不能证明它的取链行为合法。
安装第三方音源包前，请自行判断来源是否可信。
:::

另外请注意：扫描器**刻意不拦截 `eval(` 与 `Function(`**。这不是疏漏——主流第三方
加密库（crypto-js 等）普遍用 `Function("return this")()` 探测全局对象，拦了会大面积
误杀正常包；而在桥、网络与文件能力都已封死的执行环境里，动态执行代码也无法提权。
判断依据是「它能做什么」，不是「它用了什么语法」。
