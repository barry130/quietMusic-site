## 这是什么

**轻听**是一个以**本地音乐播放**为核心的播放器。装上就能用：扫描你的音乐目录，
播放、歌词、收藏、下载、统计全部可用，**全程不需要联网**。

在线能力是**可选增强**，而且被设计成一层可插拔的东西——**音源包**。
音源包不是本项目的组成部分，它由使用者自行获取与安装，取链逻辑（把一首歌变成
一个可播放地址）全部封装在里面。这样设计带来两个直接好处：

- 第三方平台的接口随时可能变动，**改接口不用发新版客户端**，推一个音源包就行；
- 本仓库因此可以只包含纯客户端代码，**不分发任何第三方取链实现**。

没装音源包时应用依然完整——只是在线搜索与播放不出现。

## 核心特性

### 🎧 本地音乐，开箱即用

扫描本地目录即成曲库，支持 **MP3 / FLAC / WAV / OGG / AAC / M4A**。
播放队列、四种循环模式、歌词、下载、收藏、听歌统计全部内置。

**Android 与 Windows 功能对齐**，两端都是完整播放器，不是「某一端为主」。

### 🔌 在线能力，来自音源包

装上音源包后，搜索、歌单广场、排行榜、新歌速递、每日推荐、歌手页、专辑页、
逐字歌词全部打开。支持 **网易云 / QQ 音乐 / 酷我 / 酷狗 / B 站 / 咪咕** 六个源。

**同歌多源**：一首歌在多个平台有资源时，播放页可以直接切换。

### 🛡️ 音源包的三层安全边界

| 层 | 机制 |
|---|---|
| 安装前 | **内容安全扫描**：命中宿主桥 / 自由外联 / 后台执行体等红线直接拒绝，给出命中词与行号 |
| 安装时 | **ed25519 签名**：官方包内置公钥硬校验，改一个字节就装不上 |
| 运行时 | **能力收缴**：包里只有 `host.request` 一个出口，`fetch` / `XMLHttpRequest` / `WebSocket` / `Worker` / 文件系统全是 `undefined` |

装完还会跑一次**冒烟自检**（真实歌曲取链 + Range 预检），不过就回滚，
不会把你卡在坏包上。

### 🎨 外观与体验

- **三套预置皮肤**：Linen（暖白纸张与珊瑚红）、Graphite（中性石墨）、
  Aurora（蓝紫通透玻璃），各带亮暗两版
- **宽屏适配**：Android 端 ≥ 720px 自动切宽屏布局
- **五段均衡器**：60Hz / 230Hz / 910Hz / 3.6kHz / 14kHz，8 种预设
- **桌面歌词**：可拖动、可锁定（点击穿透）、样式即时生效

## 三个仓库

| 仓库 | 平台 | 说明 |
|---|---|---|
| [qt-uniappx](https://github.com/barry130/qt-uniappx) | Android / iOS | UniAppX（UVue + UTS）客户端，含音频内核、悬浮窗歌词、音源包引擎等原生插件 |
| [qt-pc](https://github.com/barry130/qt-pc) | Windows | Tauri 2 + React 19 + Rust 桌面端 |
| [qt-sources](https://github.com/barry130/qt-sources) | 平台无关 | 音源实现与打包流程，产物同时服务上面两端 |

**仓库边界是清晰的**：客户端仓库里没有任何第三方平台取链实现，
音源包由使用者自行获取。这不是疏忽，是刻意的设计边界。

## 常见疑问

::: details 一定要联网才能用吗？
不用。**本地音乐是核心**，扫描目录、播放、歌词、下载、收藏、统计全部离线可用。
在线能力来自音源包，装了才有、不装就没有，且随时可以卸载。
:::

::: details 为什么音源包要单独安装？
两个原因：

1. **合规边界**：仓库只包含纯客户端代码，不存储、不分发任何音乐内容或取链实现。
2. **工程效率**：第三方接口随时可能变。拆出去之后，接口失效只需要推一个新包，
   不用等新版 App——这是这套设计最直接的收益。
:::

::: details 接口失效了怎么办？
先去设置页「音源包管理」检查更新。绝大多数失效都是推个新包就修好。
若仍不行，看 [问题答疑](/faq) 的四步排查。
:::

::: details 支持哪些音质？
标准 128k / 高品 320k / 无损 FLAC 三档，**播放与下载相互独立**。
具体能拿到哪一档取决于上游线路，客户端会优先选可用的高音质来源，
并按**实测码率**重标档位（只降不升），不虚标。
:::

::: details 支持 iOS / 鸿蒙吗？
iOS **代码层面可编译但没有正式发布**；鸿蒙暂未单独适配。
:::
