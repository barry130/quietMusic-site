## 这是什么

**轻听**是一个 Android / Windows 双端的音乐应用。装上就能用：扫描音乐目录，
播放、歌词、收藏、下载、统计全部可用，这一部分**全程不需要联网**。

在线能力（搜索、歌单、排行榜、每日推荐、在线播放）是**可选增强**，
而且被设计成一层可插拔的东西——**音源包**。

音源包不是本项目的组成部分，它由使用者自行获取与安装，
取链逻辑（把一首歌变成一个可播放地址）全部封装在里面。这样设计带来三个直接好处：

- 第三方平台的接口随时可能变动，**改接口不用发新版客户端**，推一个音源包就行；
- 本仓库因此可以只包含纯客户端代码，**不分发任何第三方取链实现**；
- 取链层与数据层可以**分开更换**——风险较高的那一半出问题，搜索与歌单体验不受牵连。

没装音源包时应用依然完整，只是在线入口不出现。

## 核心特色

### 🧩 兼容 LX 自定义源脚本

这是轻听音源体系里最实用的一点。播放包内置一个 **LX 自定义源脚本宿主**：
只要是按 LX 自定义源协议写的脚本，无需改动即可装载，并在 **Android 与 Windows
两端跑出同样的结果**。

宿主为了跑通这些脚本做的事（都写在开源仓库里）：

| 能力 | 说明 |
|---|---|
| **协议模拟** | 提供符合协议的 `lx` 对象（事件注册、请求回调、脚本自述）与 `utils.crypto` / `utils.buffer` 工具面 |
| **环境桩** | 脚本常见的 `process` / `window` 全局探测与定时器反调试被安全接住，不因环境差异崩掉 |
| **逐字节保全** | 混淆脚本体在构建流水线里被逐字节还原——打包器重打印语法树会破坏脚本自校验，导致解密轮转不收敛 |
| **挂死守卫** | 每条脚本在沙箱里实际执行一遍，看门狗盯住挂死，**挂死即中止构建**，坏脚本发不出去 |

一个播放包里可以并存**多条线路**：LX 脚本、平台官方接口、聚合脚本各有分工。
某条不通时自动换下一条，本档线路全灭时还会跨源兜底救回。

### 🔌 在线能力，来自音源包

装上音源包后，搜索、歌单广场、排行榜、新歌速递、每日推荐、歌手页、专辑页、
逐字歌词全部打开。当前支持 **网易云 / QQ 音乐 / 酷我 / 酷狗 / B 站 / 咪咕** 六个源。

**音源清单由包自己声明**，客户端不内置任何白名单——包里加一行，该源立刻在两端可选、可搜、可播放。
每个源还会声明自己有没有排行榜 / 歌单 / 歌手页 / 专辑 / 新歌流这些能力面，
没有的入口**自动隐藏**，而不是给你一个空列表。

**同歌多源**：一首歌在多个平台有资源时，播放页可以直接切换。

### 🛡️ 三层安全边界

| 层 | 机制 |
|---|---|
| 安装前 | **内容安全扫描**：命中宿主桥 / 自由外联 / 后台执行体等红线直接拒绝，给出命中词与行号 |
| 安装时 | **ed25519 签名**：官方包内置公钥硬校验，改一个字节就装不上 |
| 运行时 | **能力收缴**：包里只有 `host.request` 一个出口，`fetch` / `XMLHttpRequest` / `WebSocket` / `Worker` / 文件系统全是 `undefined` |

装完还会跑一次**冒烟自检**（真实歌曲取链 + Range 预检），不过就回滚，
不会把你卡在坏包上。

### 🎧 装不装包都完整

扫描本地目录即成曲库，支持 **MP3 / FLAC / WAV / OGG / AAC / M4A**。
播放队列、四种循环模式、歌词、下载、收藏、听歌统计全部内置。

**Android 与 Windows 功能对齐**，两端都是完整的应用，不是「某一端为主」。

### 🎨 外观与体验

- **三套预置皮肤**：Linen（暖白纸张与珊瑚红）、Graphite（中性石墨）、
  Aurora（蓝紫通透玻璃），各带亮暗两版
- **宽屏适配**：Android 端 ≥ 720px 自动切宽屏布局
- **五段均衡器**：60Hz / 230Hz / 910Hz / 3.6kHz / 14kHz，8 种预设
- **桌面歌词**：可拖动、可锁定（点击穿透）、样式即时生效

## 常见疑问

::: details 一定要联网才能用吗？
不用。扫描目录、播放、歌词、下载、收藏、统计全部离线可用。
在线能力来自音源包，装了才有、不装就没有，且随时可以卸载。
:::

::: details 为什么音源包要单独安装？
两个原因：

1. **合规边界**：仓库只包含纯客户端代码，不存储、不分发任何音乐内容或取链实现。
2. **工程效率**：第三方接口随时可能变。拆出去之后，接口失效只需要推一个新包，
   不用等新版应用——这是这套设计最直接的收益。
:::

::: details 兼容 LX 音源脚本是什么意思？
播放包里内置了一个 LX 自定义源脚本宿主，符合该协议的自定义源脚本无需改动即可装载，
并且**同一份脚本在 Android 与 Windows 两端都能跑**。脚本依旧跑在受管控的沙箱里，
只有宿主注入的网络通道可用。详见[如何设置音源](/source-setup)。
:::

::: details 接口失效了怎么办？
先去音源包管理页检查更新。绝大多数失效都是推个新包就修好。
若仍不行，看 [问题答疑](/faq) 的四步排查。
:::

::: details 支持哪些音质？
标准 128k / 高品 320k / 无损 FLAC 三档，**播放与下载相互独立**。
界面上只展示当前源真实支持的档位；客户端会优先选可用的高音质来源，
并按**实测码率**重标档位（只降不升），不虚标。
:::

::: details 支持 iOS / 鸿蒙吗？
iOS **代码层面可编译但没有正式发布**；鸿蒙暂未单独适配。
:::
